# Skill Picker 短视频口播稿

语气：跟朋友吐槽，不是讲产品。  
时长：约 45–60 秒。  
语速：偏慢一点，留出点按和切画面的空隙。

---

## 成片口播（推荐这一版）

> 装 AI 用久了，你会不会也这样——  
> skills 越装越多，真要用的时候，反而想不起名字。  
>  
> 「做周报那个叫啥来着？」  
> 「画图那个……好像装过三个？」  
> 文件夹翻半天，最后还是靠猜。  
>  
> 我就烦这个，所以做了个小工具，叫 Skill Picker。  
>  
> 用法就一步：克隆下来，跑一句  
> `python skillpick.py install`  
>  
> 完了。  
>  
> 之后你不用记名字。  
> 直接跟它说：「帮我选个 skill 做周报」——  
> 它给你甩两三个候选，你点一下就行。  
>  
> 顺手还能告诉你：哪些 skills 装重了、两边内容还对不上。  
> 只提醒，不擅自删。  
>  
> 纯本地，不上云。  
> 懒得装？评论区有 Demo，点进去就能试。

## 分镜对照（按句切）

| 时间 | 画面 | 口播 |
|---|---|---|
| 0–8s | 密密麻麻的 skills 文件夹 / 长列表往下滚 | 装 AI 用久了……真要用的时候，反而想不起名字 |
| 8–14s | 人对着对话框犹豫 / 或「翻文件夹」特写 | 「做周报那个叫啥来着？」……最后还是靠猜 |
| 14–18s | Logo / 标题出现 | 我就烦这个，所以做了个小工具，叫 Skill Picker |
| 18–26s | 终端敲 `install`，门禁绿勾闪一下 | 用法就一步……跑一句 install。完了。 |
| 26–38s | 会话里打出「做周报」→ 弹出候选 → 点选 | 不用记名字……甩两三个候选，你点一下就行 |
| 38–48s | 「理技能」tab，红色感叹号 | 哪些装重了……只提醒，不擅自删 |
| 48–58s | Demo 页面 + GitHub 地址大字 | 纯本地……评论区有 Demo，点进去就能试 |

## 备选开头（更短、更冲）

如果平台偏信息流、前 3 秒要钩子，可换成：

> 我 skills 装了一百多个。  
> 结果每次要用，还是得搜名字。  
> 这合理吗？

然后接正文「我就烦这个……」那一段。

---

## 别念的词（容易 AI 感）

- 「赋能 / 一站式 / 革命性 / 打造 / 闭环」
- 「智能匹配引擎」「四道门禁」「meta-skill」——口播里别提
- 长英文堆砌；Demo、GitHub 可以说，其余中文即可
