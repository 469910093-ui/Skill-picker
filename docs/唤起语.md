# Skill Picker 唤起语（已校验）

装好后（`python skillpick.py install`），在 Cursor / Claude 会话里说下面任一句即可。

## 找技能

| 直接说 | 说明 |
|---|---|
| 帮我选个 skill 做周报 | 最稳；把「周报」换成你的意图 |
| 用哪个 skill 能画图表？ | |
| 有没有 skill 能剪视频？ | |
| 帮我找找能做 PPT 的 skill | 口语「帮我找找…」 |
| 帮我看看本机有没有写周报的能力 | 能力盘点式 |
| 本机有没有剪视频的能力？ | |
| 你会做数据分析吗？ | 意图是找 skill / 盘点本机能力时 |
| 我要干周报了，哪个 skill 最适配我的需求？ | 开干前选型 |
| 我要干短视频了，哪个 skills 最适配？ | 同上（skills 复数也认） |
| 查找一下本机最适合的 skills | |
| 使用本机 skills 帮我做 PPT | |
| 用本机的 skill 来做飞书文档 | |
| 有哪些 skill 能做这个？ | |

## 盘点 / 整理已装 skills

| 直接说 | 说明 |
|---|---|
| 整理一下我当前安装的所有 skills | 开看板总览 + 分类梳理 |
| 本机装了哪些 skills？ | |
| skills 清单 / 都装了啥 skill | |
| skill 总览 | |

## 理技能 / 开看板

| 直接说 |
|---|
| 打开 skills 看板 |
| 理一下技能 |
| 看看有没有重复的 skill |
| 清理 skills |

## 不会抢路由

- 已点名具体 skill：如「用 work-report 写周报」→ 直接跑那个
- 普通写代码 / 通识问答（如「你会写 Python 吗」纯闲聊）→ 不抢
- 「你会…吗」仅在**找 skill / 盘点本机能力**语境下启用

## 校验结论（本机 2026-07-27）

| 环节 | 状态 |
|---|---|
| `match "做周报"` | 命中周报类 skill（如 ibu-weekly-html-report / work-report） |
| `match "画图表"` | 命中 chart-visualization 等 |
| 门禁 G1–G4 | G1/G2/G4 PASS；G3 漂移仅 WARN（正常） |
| MCP `skill_match` / `skill_dashboard` | 已注册并可调用 |
| Cursor 全局规则 | `~/.cursor/rules/skill-picker.mdc`（alwaysApply）保证话术唤起 |
| meta-skill | 已装进 Cursor / Claude / Codex / OpenClaw |

若 agent 没反应：重开 Cursor 会话（刷新 MCP 与 rules），再说一遍唤起语。
