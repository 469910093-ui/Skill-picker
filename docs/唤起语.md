# Skill Picker 唤起语（已校验）

装好后（`python skillpick.py install`），在 Cursor / Claude 会话里说下面任一句即可。

## 找技能

| 直接说 | 说明 |
|---|---|
| 帮我选个 skill 做周报 | 最稳；把「周报」换成你的意图 |
| 用哪个 skill 能画图表？ | |
| 有没有 skill 能剪视频？ | |
| 查找一下本机最适合的 skills | |
| 使用本机 skills 帮我做 PPT | |
| 用本机的 skill 来做飞书文档 | |
| 本机装了哪些 skills？ | |
| 有哪些 skill 能做这个？ | |

## 理技能 / 开看板

| 直接说 |
|---|
| 打开 skills 看板 |
| 理一下技能 |
| 看看有没有重复的 skill |
| skill 总览 |

## 不会抢路由

- 已点名具体 skill：如「用 work-report 写周报」→ 直接跑那个
- 普通写代码 / 问答，与选 skill 无关

## 校验结论（本机 2026-07-27）

| 环节 | 状态 |
|---|---|
| `match "做周报"` | 命中周报类 skill（如 ibu-weekly-html-report / work-report） |
| `match "画图表"` | 命中 chart-visualization 等 |
| 门禁 G1–G4 | G1/G2/G4 PASS；G3 漂移仅 WARN（正常） |
| MCP `skill_match` / `skill_dashboard` | 已注册并可调用 |
| Cursor 全局规则 | `~/.cursor/rules/skill-picker.mdc`（alwaysApply）保证话术唤起 |
| meta-skill | 已装进 Cursor / Claude / Codex / OpenClaw |

若 agent 没反应：重开 Cursor 会话（刷新 MCP 与 rules），再说一遍唤起语。
